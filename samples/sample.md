# PetaKit5D timeline snippets

Paste this into `web/index.html` through the file picker or reuse the same syntax in a remote markdown file:

```tcl
[petakit5d label {Markdown clip} src {https://example.org/petakit5d/markdown.md} x 320 y 320 z 24 c 1 t 72 fps 18]
```

```text
pk5d:label=Markdown byte line;source=https://example.org/petakit5d/byte.txt;x=512;y=256;z=16;c=2;t=120;fps=30
```
